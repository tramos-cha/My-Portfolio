### 2. SafeStay: IoT-Based Smart Room Monitoring System
SafeStay is an IoT-based project designed to monitor and manage room conditions using connected IoT devices, sensors, and actuators. The system demonstrates how devices communicate through a wireless network and perform automated actions based on sensor readings and configured rules.

**My Contributions:**
- Configured the IoT devices and network connections.
- Connected sensors and actuators to the IoT network.
- Set up the IoT server and device communication.
- Configured system rules for automated device responses.
- Tested the system using Cisco Packet Tracer.

**Tools Used:**
- Cisco Packet Tracer
- IoT Devices and Sensors
- Wireless Access Point
- IoT Server
- Network Configuration

**Project Files:**
The Cisco Packet Tracer simulation file (`.pkt`) is included in the repository under:

`Projects/SafeStayIoT/`
To view and run the simulation, download the `.pkt` file and open it using **Cisco Packet Tracer**.
